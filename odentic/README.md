# 오덴틱 매출·광고 대시보드 파이프라인

오덴틱 매출·광고 대시보드(Artifact)를 자동으로 새로고침하기 위한 스크립트. 바르너 파이프라인
(`../refresh.py`, `../template.html`)과 동일한 패턴으로 만들어져 있다 — 오덴틱 구글시트가 바르너
시트를 복제해서 만들어진 것이라 탭 gid가 그대로 일치한다.

- `refresh.py` — 구글시트(링크 공유, 뷰어) 2개 탭(매출_RAW_CLEAN, 오덴틱_광고소재)을 CSV로 받아
  집계하고 `template.html`에 데이터를 채워 `dashboard_output.html`을 생성한다.
- `template.html` — 대시보드 HTML/CSS/JS 템플릿. `__ODENTIC_DATA_JSON__` 자리에 집계 데이터가
  채워진다. 판매채널·제품·광고매체는 시트에 실제로 나타나는 값을 기준으로 자동 구성되므로(하드코딩
  아님), 네이버·카카오 등 신규 판매채널이나 Google·TikTok 등 신규 광고매체가 시트에 추가돼도
  코드 수정 없이 대시보드에 자동으로 반영된다.

## 사전 조건: 시트 공유 설정

`refresh.py`는 인증 없이 export CSV URL로 시트 원본을 받아오므로, 대상 구글시트
(`1fYXpZiI_TfSKx6Wo34d1YpyIYiAjl6uqM5RFU9QHF1A`)가 **"링크가 있는 모든 사용자 - 뷰어"**로
공유돼 있어야 한다. 공유 설정이 안 돼 있으면 `fetch_csv`가 로그인 페이지 HTML을 받아와서
명확한 에러 메시지와 함께 실패한다.

## 실행

```bash
python3 refresh.py
```

`dashboard_output.html`이 생성되면, Artifact 도구로 기존 오덴틱 대시보드 URL에 재배포한다.

## 알려진 제한

- 공헌이익은 매출_RAW_CLEAN 기준으로 원가15%·배송비7.5%·수수료3.2%를 일괄 적용한 근사치다.
  시트1(오덴틱 마스터)의 자사몰/판매처별 트래커가 채널별로 세분화한 수수료율(MIX%)까지는
  반영하지 않는다.
- "소재별 성과" 표는 오덴틱_광고소재 탭 전체 기간을 소재명 기준으로 누적 집계한 값이라, 대시보드
  상단의 기간 필터가 적용되지 않는다(원본이 15만 행 이상이라 일자별 소재 단위까지 통째로 내려보내면
  용량이 커지기 때문). 필요해지면 바르너의 `build_creative_winners`처럼 광고비 하한선을 두고
  일자·소재 단위로 축소해 내려보내는 방식으로 확장할 수 있다.

## 매일 자동 실행

바르너와 마찬가지로 Claude Code 예약 작업(routine)이 이 저장소를 clone해서
`python3 odentic/refresh.py`를 실행한 뒤, 결과를 기존 오덴틱 Artifact URL에 재배포하면 된다.
